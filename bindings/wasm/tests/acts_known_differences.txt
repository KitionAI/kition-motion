# Known differences between the editor state each command declares (`bindings/wasm/src/reads.json`,
# and the key-selection table `KEY_SELECTION` in `bindings/wasm/src/acts.rs`) and what the source
# scan of `tests/acts.rs` finds in the engine's code. Reviewed 2026-11-21 (task
# acts-known-differences); the full per-command audit is after the launch (2026-12-15).
#
# A strict ratchet, not a mute: the test fails on a difference that is not here word for word, and
# on an entry that no longer differs, so entries only go away. Never add an entry where the code
# reads more than its command declares: declare the read in `reads.json` (with a regression case)
# instead. The only `scan-wider` entries are reads the scan finds that the command does not make.
#
# Declared wider than the scan finds (`declared-wider`) is safe: a declared read the code does not
# make only lets the premise guard refuse more (a person changing that state after an agent's basis
# refuses the agent's step that does not give it), never less.
#
# Format: command | difference | category | reason (one line)
#   difference  declared-wider: <kinds>  declared, not found by the scan
#               scan-wider: <kinds>      found by the scan, not declared
#               key-table-missing        the scan finds a read of the key selection; not in the table
#               key-table-extra          in the table; the scan finds no read of the key selection
#   category    scanner-blind-kind       `mode`, `active`, `area`: the scan looks only for the selection, `part` and `time`
#               scanner-cannot-follow    the code reads it through a path the scan does not follow (`file.rs:line`)
#               over-declared            the code reads less than declared: safe, trimmed in the audit
#               scanner-false-read       the scan finds a read the command does not make (`file.rs:line`)
